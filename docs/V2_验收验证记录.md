## 建议进入 V2 开发前先确认

建议先输出并确认 V2 详细设计与验收条件，最小可交付范围可以收敛为：

1. 附件内容解析：支持 PDF、Word、Excel 提取文本，记录解析状态、错误原因和解析时间。
2. 关键词检索：支持公告标题、正文、附件解析文本的关键词查询。
3. 后台检索入口：在后台提供统一搜索页，可跳转公告、附件和原始地址。
4. OpenClaw 问答最小闭环：企微问题进入系统，返回基于已归档公告/附件的检索结果摘要。
5. V2 验收命令：增加 `zhengfudata v2-acceptance-check` 或等价脚本，自动验证解析、检索和问答接口。
