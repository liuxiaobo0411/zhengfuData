# 建筑资质公开信息监测与归档系统 前端 UI 详细设计

## 1. 设计定位

V1 后台是少数内部人员使用的工作台，不做营销化视觉，不做大面积装饰性首页。界面目标是让用户快速判断“今天抓到了什么、哪里失败了、哪些公告或附件发生变化、下一步该处理什么”。

前端采用安静、密集、可扫描的运营工具风格。视觉上强调来源、状态、时间、数量、变化类型和操作入口，避免用大段说明文字解释功能。

## 2. 信息架构

V1 后台包含以下一级导航：

- 工作台
- 抓取信息
- 附件管理
- 抓取任务
- 网站栏目
- 通知日志
- 系统配置

推荐布局：

```text
左侧固定导航
顶部状态栏
主内容区
  筛选区
  数据概览
  列表 / 详情 / 表单
```

左侧导航用于模块切换，顶部状态栏用于展示当前存储目录、最近一次抓取时间、OpenClaw 通知状态和手动抓取入口。

## 3. 视觉原则

### 3.1 风格

- 工具型后台，不做落地页和宣传页。
- 信息密度中高，适合反复查看和处理。
- 卡片只用于独立指标、列表项和详情分组，不做卡片嵌套。
- 页面区块保持全宽布局，核心内容限制在合适宽度内。
- 颜色服务于状态，不做单一色系堆叠。

### 3.2 色彩

推荐色彩角色：

```text
背景：#F5F7FA
主文本：#18212F
次文本：#64748B
边框：#D9E1EA
主色：#2563EB
成功：#0F9F6E
警告：#D97706
失败：#DC2626
变化：#7C3AED
附件：#0891B2
```

主界面不使用大面积渐变，不使用装饰性光斑。状态色只在标签、图标、关键数字和状态条上使用。

### 3.3 字体与字号

建议使用系统字体：

```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", "Microsoft YaHei", sans-serif;
```

字号建议：

- 页面标题：20px / 600
- 区块标题：15px / 600
- 表格正文：13px / 400
- 辅助信息：12px / 400
- 指标数字：24px / 650

不使用随视口宽度变化的字体，不使用负字距。

## 4. 核心页面设计

## 4.1 登录页

目标：只完成简单账号密码登录。

内容：

- 系统名称
- 用户名输入框
- 密码输入框
- 登录按钮
- 登录失败提示

不展示复杂产品说明，不做注册入口。

## 4.2 工作台

工作台是默认首页，用于查看每日抓取结果。

主要模块：

- 今日概览：新增公告、正文变化、附件新增、附件变化、失败栏目、附件失败。
- 最近任务：展示最近一次定时抓取和手动抓取状态。
- 变化流：按时间展示新增公告、正文变化、附件变化。
- 失败处理：展示失败站点、失败栏目、失败原因和重试入口。
- 来源健康度：展示各网站最近状态、成功率和最近抓取时间。
- 企微通知状态：展示最近通知是否成功、目标类型和失败原因。

关键操作：

- 手动抓取全部
- 手动抓取单网站
- 查看失败详情
- 查看公告详情
- 下载附件
- 跳转原始地址

## 4.3 抓取信息列表

用于查看所有公告和政府公开信息。

表格字段：

- 标题
- 信息类型
- 来源网站
- 栏目
- 发布时间
- 页面更新时间
- 变化状态
- 附件数量
- 最近抓取时间
- 操作

筛选条件：

- 来源网站
- 栏目
- 信息类型
- 发布时间范围
- 抓取时间范围
- 变化类型
- 是否有附件
- 关键词

操作：

- 查看详情
- 打开原始地址
- 下载附件
- 查看版本

## 4.4 抓取信息详情页

详情页强调“原始信息和本地归档的对应关系”。

页面结构：

- 基础信息：标题、来源、栏目、发布时间、抓取时间、原始地址。
- 变化摘要：新增、正文变化、附件新增、附件变化。
- 正文内容：展示解析后的正文文本。
- 附件列表：名称、类型、大小、hash、下载状态、下载按钮。
- 页面快照：本地 HTML 快照入口。
- 版本记录：正文 hash、附件 hash、变化时间。

## 4.5 附件管理页

用于集中查看附件下载和归档状态。

表格字段：

- 附件名称
- 类型
- 所属公告
- 来源网站
- 下载状态
- 文件大小
- hash
- 下载时间
- 失败原因
- 操作

操作：

- 下载本地附件
- 打开原始附件地址
- 重试下载
- 查看所属公告

## 4.6 抓取任务页

用于查看定时任务和手动任务。

列表字段：

- 任务编号
- 任务类型
- 触发方式
- 状态
- 开始时间
- 结束时间
- 耗时
- 计划栏目数
- 成功栏目数
- 失败栏目数
- 新增数
- 变化数
- 附件成功数
- 附件失败数
- 通知状态

详情页包含：

- 任务统计
- 栏目执行明细
- 失败日志
- 通知日志
- 重试入口

## 4.7 网站栏目页

用于维护抓取来源。

网站字段：

- 网站名称
- 首页地址
- 地区
- 主管单位
- 启用状态
- 最近抓取状态
- 最近失败原因

栏目字段：

- 栏目名称
- 栏目地址
- 信息类型
- 抓取策略
- 是否下载附件
- 是否保存快照
- 最大页数
- 时间窗口
- 请求间隔
- 列表选择器
- 详情选择器
- 附件选择器

关键操作：

- 新增网站
- 新增栏目
- 测试抓取
- 启用 / 停用
- 手动抓取

## 4.8 通知日志页

用于查看 OpenClaw 企微通知结果。

字段：

- 通知时间
- 任务编号
- 通知类型
- 目标类型
- 目标 ID
- 发送状态
- 重试次数
- 失败原因
- 响应内容摘要

操作：

- 重试通知
- 查看任务

## 4.9 系统配置页

V1 配置项：

- `storage` 根目录
- 数据库路径
- 每日抓取时间
- OpenClaw 地址
- 企微目标类型
- 企微目标用户或群 chatid
- 通知最大展示条数
- 请求超时时间
- 默认重试次数

配置页需要显示保存结果和校验错误，不允许保存空的关键路径。

## 5. 组件设计

### 5.1 状态标签

任务状态：

- `success`：绿色
- `partial_success`：橙色
- `failed`：红色
- `running`：蓝色
- `pending`：灰色

变化状态：

- 新增：蓝色
- 正文变化：紫色
- 附件新增：青色
- 附件变化：橙色
- 抓取失败：红色

### 5.2 指标卡

指标卡包含：

- 指标名称
- 主数字
- 与上次相比的变化
- 状态色短条

指标卡之间等高，不因数字变化造成布局跳动。

### 5.3 表格

表格用于高频查看，应支持：

- 固定列宽
- 标题两行截断
- 状态标签
- 行内操作按钮
- 空状态
- 加载状态
- 错误状态

### 5.4 详情抽屉

列表页可使用右侧抽屉快速查看详情。

抽屉包含：

- 基础信息
- 变化摘要
- 附件列表
- 原始地址
- 本地快照

## 6. Demo 样例范围

本次 Demo 先呈现“工作台首页”。

Demo 应包含：

- 左侧导航
- 顶部状态栏
- 今日概览指标
- 变化流
- 最近任务
- 来源健康度
- 失败处理
- OpenClaw 通知状态

Demo 是高保真视觉样例，不要求交互。

## 7. 前端验收条件

- 页面首屏能明确看出今日抓取结果。
- 用户能快速找到失败项和变化项。
- 公告、附件、任务、网站栏目之间的入口清晰。
- 视觉风格符合内部工具，不像营销官网。
- 中文标题和按钮在常见宽度下不溢出。
- 状态颜色语义一致。
- Demo 样例可打开查看。
